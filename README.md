# New Generation Connect

NEW GENERATION NETWORK – APP DEVELOPMENT PROMPT

Project Overview

Develop a modern, secure, fast, and scalable Christian mobile application called NEW GENERATION NETWORK.

Mission: To spread the Gospel of Jesus Christ, inspire lives, strengthen faith, and bring hope to people around the world through impactful Christian content.

Vision: "We are a people raised to raise a righteous generation for Christ."

The application should have a clean, modern, and professional design using blue, white, and dark theme colors with smooth animations and excellent user experience.

CONTENT MANAGEMENT

The application should support two publishing methods.

Method 1 (Recommended)

Connect the application to the ministry's official YouTube channel using the YouTube Data API.

When new videos are uploaded to YouTube, they should automatically appear inside the application under the appropriate categories.

Method 2

Allow administrators to upload devotionals, images, documents, announcements, and other ministry resources directly through the Admin Dashboard using secure cloud storage.
